[CAVI-TK10] Lógica de Cálculo de Proporción de Participación (Pi)

Criterios de Aceptación:

[CAVI-TK15] Motor de Amortización con Interés sobre Saldo Restante (Ley 176)

[CAVI-TK16] Algoritmo de Imputación de Pagos y Prelación de Cobro
Tipo: Lógica de Negocio (Backend)
Requisito: FR-09, CU-04
Estimación: 5h
Descripción:
- Crear lógica de procesamiento de pagos con la regla de prelación: mora -> interés corriente -> capital.
- Bloquear registros de cobro con importe inferior a la cuota mínima de interés del ciclo.

[CAVI-TK17] Transacción de Liquidación 50/50 y Prorrateo a Bolsas Familiares

Criterios de Aceptación:

-- 1. Tipo enumerado para roles de usuario (RBAC)
CREATE TYPE rol_usuario AS ENUM ('ADMINISTRADOR', 'COBRANZA');

-- 2. Tabla de Usuarios (CAVI-TK03 / NFR-01)
CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre_completo VARCHAR(120) NOT NULL,
    correo VARCHAR(120) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    rol rol_usuario NOT NULL DEFAULT 'COBRANZA',
    activo BOOLEAN NOT NULL DEFAULT TRUE,
    creado_en TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 3. Tabla de Clientes (CAVI-TK04 / FR-04, FR-05)
CREATE TABLE clientes (
    id SERIAL PRIMARY KEY,
    cedula VARCHAR(20) UNIQUE NOT NULL, -- Formato cédula nicaragüense
    nombres VARCHAR(100) NOT NULL,
    apellidos VARCHAR(100) NOT NULL,
    telefono VARCHAR(20) NOT NULL,
    direccion TEXT NOT NULL,
    actividad_economica VARCHAR(120),
    activo BOOLEAN NOT NULL DEFAULT TRUE,
    creado_en TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Índice para optimizar búsquedas por cédula
CREATE INDEX idx_clientes_cedula ON clientes(cedula);
