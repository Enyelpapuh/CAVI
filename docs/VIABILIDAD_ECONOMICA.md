# Viabilidad Económica

El desarrollo de este sistema no representará un cobro por honorarios para el beneficiario, ya que el proyecto se concibe como un trabajo aplicado en el cual el desarrollador asume la creación del producto. Asimismo, el ecosistema de desarrollo y los motores de bases de datos empleados (como Python, Django, PostgreSQL y Preact) se fundamentan estrictamente en software libre y de código abierto, lo que elimina por completo los gastos en licenciamiento. La infraestructura de hardware inicial también supone un costo nulo, dado que se utilizarán los equipos de cómputo personales y dispositivos móviles ya existentes.

Sin embargo, para evaluar adecuadamente la magnitud del proyecto, es indispensable cuantificar el valor real de la solución tecnológica y evidenciar el equivalente monetario que se le está ahorrando al cliente. A continuación, se presenta una tabla resumen que detalla el costo estimado de la mano de obra, el esfuerzo técnico requerido (cotizado a precio de mercado) y la estimación de los costos operativos necesarios para el alojamiento del sistema en la nube (hosting).

### Tabla Resumen de Estimación de Costos y Ahorro

| Concepto | Descripción | Esfuerzo Estimado | Costo Estimado (USD) |
| :--- | :--- | :--- | :--- |
| **Mano de Obra (Desarrollo del Sistema)** | Análisis de requerimientos, diseño de base de datos, programación Backend/Frontend, empaquetado móvil y QA. | ~160 - 200 horas (aprox. 4 a 5 Sprints) | $2,500.00 |

| **Costos Operativos de Alojamiento (Hosting)** | Alojamiento en la nube (Servidor VPS Básico para Backend y Base de Datos) proyectado a 1 año. | Pago recurrente | $120.00 - $150.00 / año |

> **Nota de Análisis:** El rubro de *Valor Total Ahorrado* refleja el monto que una agencia de software o un desarrollador independiente cobraría por construir una plataforma de nivel empresarial con las mismas características. El cliente únicamente deberá contemplar la asunción de los **Costos Operativos de Alojamiento** una vez que el sistema sea desplegado en el entorno de producción.
